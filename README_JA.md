## 🚀 主なプロジェクト

### PharmaFlow — フルスタックのHealthTechポートフォリオプロジェクト

React、TypeScript、ASP.NET Core / C#、PostgreSQL 18で開発した、医薬品情報を検索・閲覧するための個人プロジェクトです。

- **機能：** 医薬品カタログ、検索・絞り込み、医薬品の詳細、架空の薬局各店舗での取り扱い状況、薬局の詳細・営業時間を確認できます。
- **使いやすさ：** ブラウザー内に保存するお気に入り、英語・スペイン語・日本語、ライト・ダークテーマに対応しています。レスポンシブUIを採用し、アクセシビリティにも配慮しています。
- **設計・運用：** 本番環境は同一オリジン構成です。Dockerを使ってRenderにデプロイし、NeonのPostgreSQLを利用しています。データベース変更の明示的なリリース手順と、アプリ実行用の読み取り専用PostgreSQLロールを設けています。Vite、Entity Framework Core、Npgsqlを使用しています。

**検証済みテスト結果のスナップショット：** フロントエンド281件成功 · バックエンド360件成功。

架空のデモデータを使用しており、実際の医療・調剤業務向けシステムではありません。患者管理システムではなく、実在する薬局との連携も行っていません。

学校の保健室で実際に行われていた紙ベースの業務をデジタル化するために開発した、軽量なWebアプリケーションです。学校事故の申告手続きの一部を自動化しています。現場の具体的な業務課題を、実用的な方法で解決する取り組みです。
